# AgroReserva CPCE - Gestão de Áreas Experimentais

Plataforma desenvolvida para a disciplina de **Projeto Integrador II** no Campus Professora Cinobelina Elvas (UFPI/CTBJ) sob orientação do Prof. Clécio Sousa.

- **Status do Projeto:** Etapa 3 Concluída (Aplicação Web & Testes Aprovados)
- **Link da Aplicação Online (GitHub Pages):** [Acessar AgroReserva CPCE](https://luigihora2-del.github.io/Projeto_Integrador_II/)

## 📁 Estrutura do Repositório
- `/docs/index.html` - Interface Principal da Aplicação Web
- `/docs/style.css` - Estilização Visual Responsiva
- `/docs/script.js` - Lógica de Negócio e Persistência de Dados (`localStorage`)
- `/docs/testes.md` - Relatório de Validação e Matriz de Testes Executados
- `Requisitos.md` - Especificação de Requisitos da Aplicação
- `modelagem.md` - Modelagem do Sistema

## 🧪 Validação e Testes
Todos os testes manuais, funcionais, de usabilidade mobile/desktop e de publicação foram executados com 100% de aprovação. O relatório completo pode ser consultado em [`docs/testes.md`](docs/testes.md).
